# Changelog

## 1.0.0

First release.

- Full page, Select area and Visible capture.
- Full-page engine: fixed/sticky UI shown once, lazy-content pre-scroll, inner scroll containers, HiDPI, automatic split into parts for very tall pages, clean stop when you switch tabs.
- Capture delay (Off, 3, 5, 10 s) from the popup, with an on-page countdown that never appears in the capture; Esc cancels.
- Result tab: copy, save as PNG/JPEG/WebP, crop, redact (solid or pixelate), annotate (arrow, rectangle, freehand, text, highlight), undo.
- Filename templates, optional embedded capture metadata, save-to-Downloads or ask-where-to-save.
- Settings with About/Help and Copy diagnostic info.
